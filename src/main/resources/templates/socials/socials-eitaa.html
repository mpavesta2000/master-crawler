راهنمای تنظیم ربات ایتا
تنظیم ربات:
  1. وارد وب‌سایت یا اپ ایتا شوید
  2. از بخش API درخواست ربات دهید
  3. توکن دریافتی را کپی کنید
  4. کانال یا گروه مقصد ایجاد کنید
تنظیم کانال:
  1. ربات را به کانال اضافه کنید
  2. دسترسی مدیریت پیام‌ها را بدهید
  3. ID کانال را دریافت کنید
  4. ID را در فرم وارد کنید
توجه: API ایتا ممکن است محدودیت‌هایی داشته باشد. حتماً مستندات رسمی را مطالعه کنید.
پس از تنظیم، تمام کاربران می‌توانند از این ربات برای انتشار اخبار در ایتا استفاده کنند.
