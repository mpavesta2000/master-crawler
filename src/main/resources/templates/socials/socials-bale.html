راهنمای تنظیم ربات بله
۱. ایجاد ربات:
  1. در بله، @BotFather را پیدا کنید
  2. دستور /newbot را ارسال کنید
  3. نام و نام کاربری ربات را انتخاب کنید
  4. توکن دریافتی را کپی کنید
۲. تنظیم کانال:
  1. ربات را به کانال اضافه کنید
  2. دسترسی مدیریت پیام‌ها را بدهید
  3. ID کانال را پیدا کنید
  4. ID را در فرم وارد کنید
یافتن Chat ID:
  • از ربات‌های شناسایی ID استفاده کنید
  • برای کانال‌ها ID منفی است
  • برای گروه‌ها ID منفی است
پس از تنظیم، تمام کاربران می‌توانند از این ربات برای انتشار اخبار در بله استفاده کنند.
